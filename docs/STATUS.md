## 남은 작업
1. Developer ID 인증서가 준비되면 docs/RELEASE.md 4~6절을 수행하고 결과를 TESTING.md에 기록.
2. docs/TESTING.md "검증 대기" 표의 수동 항목 확인(VoiceOver, 미디어 키, Bluetooth, 잠자기, 드래그 앤 드롭, 파일 패널).
3. 출력 품질 옵션을 실제 USB DAC에서 확인(비트 깊이 전환, 곡 사이 틈, 독점 중 다른 앱 소리의 행방)하고 옵션을 켠 채 장시간 재생.
4. 실제 FLAC 8곡은 확인함(TESTING.md "실제 음악 파일"). FLAC 외 포맷과 대규모 실제 라이브러리로 스캔·재생을 확인하고 발견되는 태그/코덱 문제를 기록.
5. 공개 배포 전 라이선스 전문 묶음 추가(RELEASE.md 7절).
6. Windows판을 실제 Windows에서 실행해 docs/TESTING.md "Windows"의 미확인 항목을 확인하고, 그 뒤에 지원 환경으로 적는다.
7. 음량 보정을 귀로 확인한다: `dist/listening/leveling-ab.wav`(없으면 `oneum-libtool leveled <폴더> --ab <파일>`로 다시 만든다)를 듣거나, 음량 보정을 켜고 여러 앨범을 이어 듣는다. 출력의 음량을 잰 결과는 docs/TESTING.md "보정된 출력의 음량".
   5만 곡 분석은 3분의 1에서 멈췄으므로(문제는 없었음) 끝까지 한 번 돌린다.
8. 새 단축키(⌥⌘→, ⌥⌘←, ⌘⇧.)를 실제 키보드로 눌러 본다.

## 재개 지점
1. 이 파일과 docs/TESTING.md를 읽는다.
2. `cargo test --workspace --locked`로 현재 상태를 확인한다.
3. 앱을 띄워 확인하려면 docs/TESTING.md "앱 구동 검증"의 세 명령을 쓴다(실제 사용자 데이터와 분리된 프로필).
