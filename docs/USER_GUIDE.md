# OnEum 사용 안내

## OnEum이라는 이름
**OnEum**은 우리말 **온음**을 로마자로 적은 이름이고, "온음"이라고 읽습니다.
- **온**은 "온 세상", "온종일"처럼 '모든, 온전한'을 뜻하는 우리말이고 **음(音)**은 소리입니다. 가지고 있는 음악을 빠짐없이, 있는 그대로 **온전하게** 듣는다는 뜻입니다. 파일을 바꾸지 않고, 곡 사이를 끊지 않고, 소리에 손대는 처리는 사용자가 켠 것만 한다는 이 프로그램의 원칙이 여기서 나왔습니다.
- 음악에서 **온음**은 반음 둘을 합친 음정(whole tone)이고, 온음표는 가장 길게 이어지는 음표입니다. 앱 아이콘이 오선 위의 온음표입니다.
- 영어 **on**(켜다)과도 겹칩니다. 폴더만 추가하면 음악이 바로 켜집니다.

## 시작하기
1. OnEum을 열고 **음악 폴더 추가**를 누릅니다(또는 음악 폴더를 창이나 Dock 아이콘에 끌어다 놓습니다).
2. 폴더 안의 음악이 목록에 나타나기 시작합니다. 스캔이 끝나기를 기다릴 필요 없이 곡을 **더블클릭**하면 재생됩니다.
3. 폴더는 여러 개 추가할 수 있습니다. 파일을 새로 넣거나 지우면 목록이 자동으로 갱신됩니다.

- 폴더를 추가하지 않고 음악 파일만 열 수도 있습니다: **파일 → 음악 파일 열기**(⌘O), 또는 파일을 창이나 Dock 아이콘에 끌어다 놓기. 그 파일들이 대기열이 되어 바로 재생되고, "개별 추가한 곡"으로 라이브러리에 남습니다.
- OnEum은 음악 파일을 읽기만 합니다. 파일이나 태그를 바꾸거나 지우지 않습니다. 즐겨찾기, 재생 횟수, 플레이리스트, 앱이 측정한 음량은 모두 앱 자신의 데이터에 저장합니다.
- 계정도 인터넷 연결도 필요 없습니다. 가사·표지·곡 정보는 파일과 그 폴더에 들어 있는 것만 보여 줍니다.
- 이 안내는 메뉴 막대의 **도움말 → OnEum 사용 안내**에서 언제든 다시 열 수 있습니다. 왼쪽 목차를 누르면 그 항목으로 이동하고, Esc로 닫습니다.

## 화면
- **왼쪽**: 모든 곡 · 앨범 · 아티스트 · 장르 · 즐겨찾기 · 다시 듣기 · 폴더 · 통계, 그 아래에 플레이리스트(스마트 플레이리스트가 먼저 나옵니다). 고정한 항목이 있으면 맨 위에 먼저 나옵니다.
- **가운데**: 곡 목록이나 앨범 표지. 맨 아래에 곡 수와 전체 길이가 나옵니다.
- **위쪽**: 왼쪽에 검색 칸, 오른쪽에 버튼 다섯 개 — 이퀄라이저, VU 미터, 설정, 재생 대기열, 곡 정보.
- **오른쪽**: 재생 대기열 또는 곡 정보 패널(위쪽 버튼이나 ⌘U, ⌘I로 열고 닫습니다).
- **아래**: 지금 재생 중인 곡, 셔플 · 이전 · 재생 · 다음 · 반복, 재생 위치, 볼륨. 표지를 누르면 그 앨범으로, 제목을 누르면 목록에서 그 곡이 있는 곳으로 갑니다(⌘L).
- 앨범이나 아티스트, 장르를 누르면 그 안의 곡이 열리고, **뒤로** 버튼으로 돌아옵니다. **장르**에는 태그에 적힌 장르가 곡 수와 함께 모입니다(한 곡에 장르가 여럿이면 각각에 들어갑니다).
- **사이드바에 고정**: 앨범·아티스트·장르·플레이리스트를 오른쪽 클릭 → **사이드바에 고정**하면 왼쪽 맨 위 "고정"에 모입니다(12개까지). 고정한 항목을 오른쪽 클릭 → **고정 해제**.
- **폴더**: 음악 폴더를 디스크의 폴더 구조대로 둘러봅니다. 위쪽 경로의 이름을 누르면 그 폴더로, 그 아래 단추를 누르면 하위 폴더로 들어갑니다. 목록에는 그 폴더 안의 모든 곡이 경로 순서로 나옵니다.
- **통계**: 이 컴퓨터에 남은 재생 기록으로 최근 7일·30일·1년·전체 동안 들은 횟수와 시간, 많이 들은 아티스트·앨범·곡·장르를 보여 주고, 라이브러리의 형식·샘플레이트 구성도 보여 줍니다. 이름을 누르면 그곳으로 갑니다.

## 듣기
- 곡을 더블클릭하면(또는 고르고 Return) 지금 보이는 목록 전체가 대기열이 되고 그 곡부터 재생됩니다. 검색하거나 정렬한 상태라면 그 결과가 그대로 대기열이 됩니다.
- 앨범 보기에서 표지에 포인터를 올리면 나오는 ▶ 버튼으로 앨범을 바로 재생합니다.
- Space로 재생과 일시정지를 오갑니다. 재생 위치 막대를 끌거나 눌러 곡 안에서 이동하고, ⌥⌘→ / ⌥⌘←로 5초씩 앞뒤로 움직입니다.
- **이전 곡** 버튼은 3초 넘게 들은 상태에서는 지금 곡을 처음부터, 그 전에는 앞 곡으로 갑니다.
- **반복**은 끔 → 전체 → 한 곡 순서로 바뀝니다. 한 곡 반복 중에도 다음/이전 버튼은 다른 곡으로 넘어갑니다.
- **셔플**을 켜면 지금 곡을 맨 앞에 두고 대기열이 섞이고, 끄면 원래 순서로 돌아옵니다. 셔플 중의 이전 곡은 방금 들은 곡입니다.
- **앨범 단위로 셔플**(설정 → 재생 → 재생 순서): 셔플이 앨범의 순서만 섞고, 앨범 안의 곡은 순서대로 끊김 없이 이어집니다.
- **긴 곡은 이어 듣기**(설정 → 재생 → 재생 순서, 기본 켜짐): 20분이 넘는 곡(DJ 믹스, 오디오북, 긴 클래식 곡)은 다시 고르면 멈춘 곳에서 시작합니다. 앨범이 이어서 재생될 때와 끝까지 들은 곡은 처음부터 나옵니다.
- **현재 곡이 끝나면 정지**(제어 메뉴, ⌘⇧., 또는 재생 버튼을 오른쪽 클릭): 지금 곡을 끝까지 듣고 멈춥니다. 켜져 있는 동안 볼륨 옆에 "곡 끝에 정지"라고 표시되고, 그 글자를 누르면 꺼집니다. 다음 곡이 준비된 채로 멈추므로 재생을 누르면 이어지고, 그 한 곡에만 적용됩니다(다른 곡으로 넘기면 풀립니다).
- **잠자기 타이머**(제어 → 잠자기 타이머, 또는 재생 버튼을 오른쪽 클릭): 15분·30분·45분·1시간·1시간 30분 뒤에 재생을 멈춥니다. 마지막 몇 초 동안 소리가 서서히 줄어들고, 볼륨 설정은 그대로 남습니다. 켜져 있는 동안 볼륨 옆에 남은 시간이 보이며, 그 숫자를 누르면 꺼집니다.
- 볼륨은 오른쪽 아래 슬라이더나 ⌘↑ / ⌘↓로 조절합니다. 스피커 아이콘(⌘⇧M)은 음소거이고, 다시 누르면 전의 볼륨으로 돌아옵니다.
- 재생 위치 오른쪽의 시간을 클릭하면 전체 길이와 남은 시간이 번갈아 나옵니다.
- 앨범의 곡들은 사이가 끊기지 않고 이어집니다(형식별 차이는 "지원하는 파일").
- 창을 닫아도(⌘W) 음악은 계속 나옵니다. Dock의 OnEum 아이콘을 누르면 창이 다시 열립니다. 끝내려면 ⌘Q.
- 다시 실행하면 대기열과 듣던 위치가 그대로 돌아옵니다. 소리는 재생 버튼을 눌러야 납니다.
- 키보드의 재생·이전·다음 키와 제어 센터의 "지금 재생 중"으로도 조작할 수 있습니다.

## 곡 목록
- 열 제목을 누르면 그 열로 정렬됩니다. 다시 누르면 반대로, 한 번 더 누르면 원래 순서(아티스트 → 앨범 → 트랙 번호)로 돌아옵니다.
- ⌘클릭이나 ⇧클릭으로 여러 곡을 고릅니다. ⌘A는 전체 선택입니다. ↑↓로 이동하고 ⇧↑↓로 범위를 늘리거나 줄입니다. Home/End, Page Up/Down도 됩니다.
- 곡을 오른쪽 클릭하면 **재생**, **다음에 재생**, **대기열 끝에 추가**, **플레이리스트에 추가**, **즐겨찾기**, **앨범으로 이동**, **아티스트로 이동**, **Finder에서 보기**, **곡 정보**를 쓸 수 있습니다. 여러 곡을 고른 상태면 재생·추가·즐겨찾기는 모두에 적용됩니다. **라이브러리에서 제거**는 곡을 라이브러리와 플레이리스트에서만 빼고 파일은 그대로 둡니다. 폴더를 다시 스캔해도(앱을 다시 열어도) 돌아오지 않으며, **설정 → 라이브러리 → 제거한 곡 되돌리기**로 모두 다시 넣을 수 있습니다(CUE 시트로 나뉜 곡이 아니면 그 파일을 직접 열거나 창에 끌어 놓아도 다시 들어옵니다).
- 같은 동작이 메뉴 막대의 **곡** 메뉴에도 있습니다. 선택한 곡에 적용되고, 선택이 없으면 재생 중인 곡에 적용됩니다.
- **즐겨찾기**: 곡 줄의 하트를 누르거나 ⌘D. 왼쪽의 즐겨찾기에 모입니다.
- 목록을 한 번 클릭한 뒤 글자를 치면 그 글자로 시작하는 곡으로 바로 이동합니다.
- 곡이나 앨범을 끌어서 플레이리스트나 대기열에 놓을 수 있습니다.
- **열 고르기**: 열 제목을 오른쪽 클릭하면 **연도 · 장르 · 재생(횟수) · 추가(한 때) · 마지막 재생 · 포맷** 열을 켜고 끌 수 있습니다. 메뉴는 열린 채로 있으니 여러 개를 고르고 바깥을 눌러 닫습니다. 연도·재생·추가·마지막 재생·포맷 열은 제목을 눌러 정렬할 수 있습니다. 창이 좁으면 뒤쪽 열부터 잠시 숨겨집니다.
- 재생 횟수는 곡 길이의 절반(긴 곡은 4분)을 실제로 들었을 때 한 번 올라갑니다. 넘겨 버린 곡은 세지 않습니다.

## 검색
- 위쪽 검색 칸(⌘F)에 입력하면 제목·아티스트·앨범에서 바로 찾습니다. Esc로 지웁니다. 지금 열려 있는 보기(모든 곡, 앨범, 플레이리스트 …) 안에서 찾습니다.
- 일부만 입력해도 됩니다: `이유` → 아이유, `bea` → The Beatles. 대소문자는 가리지 않습니다.
- 한글 자음만 입력하면 초성으로 찾습니다: `ㅇㅇㅇ` → 아이유.
- 띄어 쓴 단어는 모두 포함된 곡만 나옵니다. 큰따옴표로 묶으면 그 구절 그대로 찾습니다: `"let it be"`.
- 찾을 곳을 정할 수 있습니다: `artist:아이유`, `album:꽃갈피`, `title:밤`, `genre:재즈`, `format:flac`. 한글 이름(`가수:`, `앨범:`, `제목:`, `장르:`, `연도:`, `형식:`)도 되고, 다른 단어와 섞어 써도 됩니다: `genre:rock year:1969 sun`.
- 연도는 범위로도 찾습니다: `year:1994`, `year:1990-1999`, `year:>=2000`, `year:<1980`.
- `format:lossless`(무손실: FLAC·ALAC·WAV·AIFF)와 `format:lossy`도 있습니다. 장르는 `genre:`를 붙였을 때만 찾습니다.
- 들은 기록으로도 찾습니다: `plays:>=5`(재생 횟수, 범위와 비교는 연도와 같음 — 한 번도 안 들은 곡은 `plays:0`), `fav:yes` / `fav:no`(즐겨찾기), `added:30d`(최근 30일 안에 추가), `played:1y`(최근 1년 안에 들음). 기간은 `d`(일)·`w`(주)·`m`(달)·`y`(년)로 적고, 한글로 `재생:`, `즐겨찾기:예`, `추가:30일`, `들은:6개월`처럼 써도 됩니다.
- 파일 검사의 결과로도 찾습니다: `check:damaged`(손상), `check:ok`(정상), `check:none`(검사하지 않음), `dr:<8`(다이내믹 레인지 — 범위와 비교는 연도와 같음). 한글로는 `검사:손상`.
- **검색을 저장**: 모든 곡에서 검색어를 입력하면 검색 칸 오른쪽에 **＋**가 나타납니다. 누르고 이름을 붙이면 그 검색이 스마트 플레이리스트가 됩니다("플레이리스트" 참고).
- 검색 칸에 포인터를 올리면 이 쓰는 법이 짧게 나옵니다.

## 대기열
- 오른쪽 위 목록 버튼(⌘U)으로 엽니다. 실제로 재생되는 순서대로 보이고, 지금 곡이 표시됩니다.
- 항목을 끌어서 순서를 바꾸거나, 오른쪽 클릭으로 위/아래 이동·제거할 수 있습니다. 항목을 더블클릭하면 그 곡으로 건너뜁니다.
- **다음에 재생**(⌘Return)은 지금 곡 바로 뒤에, **대기열 끝에 추가**(⌘⇧Return)는 맨 뒤에 넣습니다. 같은 곡을 여러 번 넣어도 됩니다.
- 곡이나 앨범을 대기열 패널(또는 닫혀 있을 때는 오른쪽 위 목록 버튼)로 끌어다 놓으면 대기열 끝에 추가됩니다.
- 대기열 위쪽의 **저장**은 지금 대기열을 그대로 새 플레이리스트로 만들고, **대기열 비우기**는 모두 지웁니다.
- 대기열 항목을 한 번 클릭한 뒤에는 키보드로도 다룹니다: ↑↓ 이동, Return 재생, Delete 제거, ⌥↑/⌥↓ 순서 바꾸기.
- 재생할 수 없는 곡(파일 없음, 손상)은 이유를 알리고 건너뜁니다.

## 플레이리스트
- 사이드바의 **+** 또는 ⌘N으로 만듭니다. 곡을 오른쪽 클릭 → **플레이리스트에 추가**.
- 곡이나 앨범을 사이드바의 플레이리스트로 끌어다 놓아도 추가됩니다. "플레이리스트" 제목에 놓으면 새 플레이리스트가 됩니다.
- 플레이리스트 이름을 더블클릭(또는 오른쪽 클릭 → 이름 변경)하면 이름을 바꿉니다.
- 플레이리스트 안에서 곡을 끌어 순서를 바꿉니다. 곡을 고르고 Delete를 누르면 플레이리스트에서 빼고, 아래 알림 줄의 **실행 취소**로 되돌릴 수 있습니다.
- 오른쪽 클릭 → **M3U8로 내보내기**, 파일 메뉴 → **플레이리스트 가져오기**(또는 `.m3u8`·`.m3u` 파일을 OnEum으로 열기). 예전 한국어 Windows에서 만든(EUC-KR) 목록도 읽습니다. 다른 컴퓨터를 가리키는 네트워크 경로는 따라가지 않습니다.
- 열려 있는 플레이리스트는 파일 메뉴에서도 이름 변경·내보내기·삭제할 수 있습니다.
- **스마트 플레이리스트**는 저장해 둔 검색입니다(돋보기 아이콘). 곡을 담아 두는 것이 아니라 열 때마다 조건에 맞는 곡을 다시 모으므로, 새 곡을 추가하거나 많이 들으면 내용이 저절로 바뀝니다. 예: `genre:재즈 format:lossless`, `added:30d`(이번 달에 들어온 곡), `plays:0`(아직 안 들은 곡), `fav:yes year:1990-1999`.
  - 만들기: 모든 곡에서 검색한 뒤 검색 칸의 **＋**. 100개까지 둘 수 있습니다.
  - 오른쪽 클릭: **재생**, **검색 조건 고치기**(검색 칸에 조건을 다시 불러옵니다 — 고친 뒤 ＋로 같은 이름에 저장하면 바뀝니다), **이름 변경**, **삭제**.
  - 스마트 플레이리스트 안에서도 검색 칸으로 더 좁혀 볼 수 있습니다. 곡을 끌어다 넣거나 순서를 바꿀 수는 없습니다.
- 플레이리스트를 지워도 음악 파일은 지워지지 않습니다.

## 다시 듣기와 라디오
- **다시 듣기**(왼쪽 목록): 위쪽의 네 탭으로 **최근 재생**, **최근 추가**(라이브러리에 새로 들어온 순), **많이 들은 곡**, **오래 안 들은 곡**(들은 적이 있지만 30일 넘게 듣지 않은 곡, 오래된 순)을 봅니다. 각 300곡까지 보여 줍니다.
- **라디오**(설정 → 재생의 "대기열이 끝나면 이어서 재생", 기본 꺼짐): 켜 두면 대기열의 마지막 곡이 시작될 때 그 곡과 어울리는 곡 다섯 곡을 라이브러리에서 골라 대기열 끝에 더합니다. 그래서 음악이 끊기지 않습니다.
  장르·아티스트·연도가 가까운 곡을 먼저 고르고, 방금(2시간 안에) 들은 곡과 같은 아티스트가 세 곡 이상 이어지는 것은 피합니다. 인터넷을 쓰지 않습니다.
  반복 재생이 켜져 있으면 동작하지 않습니다. 더해진 곡은 대기열에서 평소처럼 지우거나 옮길 수 있습니다.

## 네트워크의 미디어 서버
같은 네트워크에 있는 미디어 서버(NAS의 DLNA·UPnP 서버 등)의 음악을, 공유 폴더를 연결하지 않고 둘러보며 들을 수 있습니다.
- 왼쪽의 **네트워크**를 누르면 서버를 찾습니다. OnEum이 네트워크에 말을 거는 것은 이 화면을 열었을 때와 서버를 추가할 때뿐입니다.
- 찾은 서버가 없으면 **주소로 추가…**에 서버의 주소(`192.168.0.10` 같은 숫자 주소, 또는 `http://`로 시작하는 장치 설명 주소)를 넣습니다. 추가한 서버는 기억하고, 오른쪽 클릭으로 목록에서 지웁니다.
- 서버를 누르면 서버가 보여 주는 폴더가 나옵니다. 폴더를 눌러 들어가고 뒤로 버튼으로 올라옵니다. 곡을 더블클릭하면 그 폴더의 곡이 대기열에 들어가 그 곡부터 재생됩니다. 오른쪽 클릭으로 **다음에 재생**, **대기열 끝에 추가**를 고를 수 있고, 위의 **재생**과 **대기열 끝에 추가**는 폴더 전체에 적용됩니다.
- 서버의 곡은 보관함에 들어가지 않습니다. 곡 목록·검색·통계에 나오지 않고 즐겨찾기나 플레이리스트에 넣을 수 없습니다. 대기열에는 남아서, 다음에 열어도 이어 들을 수 있습니다.
- 재생할 수 있는 것은 서버가 원본 파일을 그대로 주는 FLAC · WAV · AIFF · ALAC · AAC(MP4) · MP3 · Ogg Vorbis · DSD입니다. 서버가 다른 형식으로 바꿔서만 주는 곡은 흐리게 나오고 재생되지 않습니다.
- 곡은 받는 대로 메모리에 올려 재생하므로, 도중에 네트워크가 잠깐 끊겨도 그 곡은 이어집니다. 음량 보정(ReplayGain)은 서버의 곡에 적용되지 않습니다.

## 곡 정보 (⌘I)
오른쪽 위의 ⓘ 버튼이나 ⌘I로 엽니다. 재생 중인 곡의 정보가 나오고, 다른 곡은 오른쪽 클릭 → **곡 정보**(⌥⌘I)로 봅니다.
- 표지, 제목, 아티스트, 앨범, 트랙 번호, 연도, 장르, 길이, 포맷, 샘플레이트, 채널, 비트 깊이, 비트레이트, 파일 크기, 음량 보정 값, 재생 횟수, 파일 위치(**Finder에서 보기**).
- **이어 가기**: 아티스트와 앨범, 장르를 누르면 그 아티스트·앨범·장르의 곡으로 갑니다. 장르가 여러 개 적혀 있으면 하나씩 따로 누를 수 있습니다.
- **크레딧과 작품 정보**: 파일에 적혀 있으면 작곡·작사·지휘·편곡·연주·프로듀서·엔지니어·믹스·리믹스, 그리고 작품·악장·레이블·카탈로그 번호·녹음일·발매일을 보여 줍니다. 크레딧의 이름이 라이브러리에 있는 아티스트이면 눌러서 갈 수 있습니다.
- **이 곡의 다른 버전**: 같은 제목·아티스트의 곡이 라이브러리에 더 있으면(다른 앨범, 다른 포맷) 음질이 높은 순으로 여섯 개까지 나옵니다. 누르면 그 버전의 정보를 봅니다.
- **가사**: 파일의 태그에 가사가 들어 있거나, 곡과 같은 이름의 `.lrc`·`.txt` 파일이 같은 폴더에 있으면 보여 줍니다. 가사에 시간 표시가 있으면(`.lrc`) 재생 위치에 맞춰 지금 줄을 강조하며 따라 내려가고, 줄을 누르면 그 줄부터 재생합니다. 예전 한국어 Windows에서 저장한(EUC-KR) 가사 파일도 읽습니다. 가사를 인터넷에서 찾아오지는 않습니다.
- 가사 파일에 같은 시각으로 번역이나 발음이 함께 적혀 있으면 원문 아래에 작게 함께 보여 주고, 함께 강조합니다.
- **파일 검사 결과**: 검사한 곡은 **무결성**(정상(MD5 일치) / 정상(끝까지 디코드됨) / 손상됨), **다이내믹 레인지**(DR 값, 앨범 값과 함께), **트루 피크**가 나옵니다("파일 검사" 참고).
- **음량 보정 값** 뒤에 "(앱 측정)"이 붙어 있으면 파일의 태그가 아니라 앱이 잰 값입니다("음량 보정" 참고).

## 신호 경로
곡 정보 패널의 **신호 경로**는 재생 중인 곡이 파일에서 출력 장치까지 가는 동안 앱이 하는 일을 순서대로 보여 줍니다. 예: `소스 FLAC · 44,100 Hz · 16 bit → 리샘플링 44,100 → 48,000 Hz → 이퀄라이저 록 → 출력 MacBook Pro 스피커 · 48,000 Hz`.
- 오른쪽 위의 한마디가 요약입니다. **원본 그대로**: 앱이 샘플을 바꾸지 않습니다. **사용자 조정**: 음량 보정·이퀄라이저·크로스피드·앱 볼륨처럼 직접 켠 기능이 소리를 바꾸고 있습니다. **변환**: 이 장치로 내보내려고 샘플레이트·채널·비트 깊이를 바꾸고 있습니다. 한마디에 마우스를 올리면 설명이 나옵니다.
- 점의 색이 단계의 종류입니다: 보라색은 사용자가 켠 조정, 청록색은 장치에 맞춘 변환, 호박색은 피크 보호.
- 나올 수 있는 단계: DSD → PCM 변환, 채널 변환(모노나 5.1·7.1 파일을 스테레오로), 음량 보정, 리샘플링, 이퀄라이저, 헤드폰 보정, 크로스피드, 피크 보호, 앱 볼륨, 디더.
- **피크 보호**는 그 곡에서 최대 음량(0dBFS)을 넘는 순간이 있어, 소리가 잘려 찌그러지지 않도록 그 순간에만 음량을 살짝 낮췄다는 뜻입니다. 넘는 순간이 없는 곡에는 아무것도 하지 않습니다.
- **디더**는 16·24비트 장치로 내보낼 때 반올림 때문에 생기는 왜곡을 막으려고 아주 작은 잡음을 더했다는 뜻이며, 샘플을 그대로 내보낼 때는 넣지 않습니다.
- "원본 그대로"는 앱 안에서의 이야기입니다. 그 뒤의 운영체제·드라이버·DAC 구간은 앱이 확인할 수 없습니다.

## 음량 보정
곡마다 녹음된 음량이 달라 볼륨을 계속 만지게 되는 것을 줄여 줍니다. 설정 → 재생 → **음량 보정 (ReplayGain)**에서 켭니다. 처음에는 꺼져 있습니다.
- **곡 기준**: 모든 곡을 같은 음량으로 맞춥니다. 여러 앨범의 곡을 섞어 들을 때 좋습니다.
- **앨범 기준**: 앨범 전체를 한 덩어리로 맞춥니다. 앨범 안에서 조용한 곡은 조용하게, 큰 곡은 크게 남습니다. 앨범을 통째로 들을 때 좋습니다. 앨범 값이 없는 곡은 곡 기준 값을 씁니다.
- **프리앰프**: 보정한 곡의 음량을 한꺼번에 더 올리거나 내립니다. 슬라이더를 더블클릭하면 0dB로 돌아갑니다. 보정 값이 없는 곡에는 적용하지 않습니다.
- **클리핑 방지**(기본 켜짐): 보정 때문에 소리가 찌그러지지 않도록 이득을 제한합니다. 꺼 두어도 최대 음량을 넘는 순간은 잘리지 않고 "피크 보호"가 눌러 줍니다.
- 보정 값은 먼저 **파일의 ReplayGain 태그**에서 가져옵니다. 다른 프로그램이 넣어 둔 태그가 있으면 그 값을 그대로 씁니다.
- **태그가 없는 곡**은 그대로 재생합니다. 이런 곡도 맞추려면 설정 → 재생 → **태그 없는 곡 분석**에서 **분석 시작**을 누릅니다. 앱이 곡을 끝까지 읽어 음량을 재고(방송 표준 EBU R 128 방식, 기준 −18 LUFS), 그 값을 태그처럼 씁니다.
  - 분석할 곡 수와 진행 상황이 표시됩니다. 음악을 들으면서 해도 됩니다. **중지**로 멈췄다가 나중에 이어서 할 수 있습니다.
  - 분석 결과는 앱 안에만 저장하고 **음악 파일은 바꾸지 않습니다**.
  - 태그가 하나도 없는 앨범은 앨범 전체를 한 번에 재서 "앨범 기준" 값도 만듭니다.
  - 파일이 바뀌면 그 곡은 다시 분석 대상이 됩니다. 새로 추가한 곡은 자동으로 분석하지 않으니 필요할 때 다시 눌러 주세요.
  - **앱이 측정한 값 → 지우기**로 모두 없앨 수 있습니다(다시 분석하면 됩니다). 읽지 못한 곡은 기억해 두었다가 다시 분석할 때 건너뛰며, 파일이 바뀌거나 앱을 다시 시작하거나 지우기를 누르면 다시 시도합니다.
- 예전 방식의 프로그램(mp3gain 등)이 넣은 태그는 재는 방법이 달라, 앱이 잰 곡과 견주면 곡에 따라 1~2dB쯤 다르게 들릴 수 있습니다. 태그가 있는 곡은 언제나 태그를 따릅니다.
- 보정이 적용되고 있는지는 곡 정보의 **신호 경로**에 "음량 보정" 단계로 나옵니다. VU 미터도 보정된 레벨을 보여 줍니다.

## 이퀄라이저 (⌘E)
위쪽의 슬라이더 모양 버튼이나 **보기 → 이퀄라이저**, 설정 → 재생의 **이퀄라이저 → 열기**로 엽니다. 버튼은 이퀄라이저가 소리를 바꾸고 있는 동안 강조색으로 켜집니다.
- **대역 10개**(32Hz ~ 16kHz, 한 옥타브 간격)와 **프리앰프**를 ±12dB 범위에서 0.5dB 단위로 조절합니다. 끌거나 클릭해서 맞추고, **더블클릭하면 0dB**로 돌아갑니다. 슬라이더에 초점이 있으면 ↑↓로 한 칸씩 움직입니다.
- 위쪽 곡선은 지금 값이 주파수별로 소리를 얼마나 올리고 내리는지 보여 줍니다. 각 대역은 제 슬라이더 바로 위에 있습니다.
- **프리셋**: 플랫, 저음 강화, 저음 줄이기, 고음 강화, 보컬, 라우드니스(작은 음량용), 팝, 록, 재즈, 클래식, 일렉트로닉, 어쿠스틱이 들어 있습니다. 고르면 바로 켜집니다. 슬라이더를 움직이면 "사용자 설정"으로 바뀝니다.
- **내 프리셋**: 이름을 적고 **내 프리셋으로 저장**을 누르면 지금 값이 그 이름으로 저장되어 프리셋 목록 아래쪽에 나타납니다(40개까지). 같은 이름으로 다시 저장하면 값이 바뀝니다. 내 프리셋을 고른 상태에서는 **이 프리셋 삭제**가 보입니다.
- 오른쪽 위의 스위치로 켜고 끕니다. **초기화**는 모든 값을 0dB로 되돌립니다. 꺼 두거나 모든 값이 0dB이면 소리를 전혀 건드리지 않습니다.
- 조절한 소리는 1초 안에 들립니다(미리 디코드해 둔 만큼 지나야 합니다). 값이 바뀔 때 소리가 튀지 않도록 부드럽게 옮겨 갑니다.
- 대역을 올리면 소리가 최대 음량을 넘을 수 있습니다. 올린 만큼 프리앰프를 내려 두면 넘지 않고(기본 프리셋은 그렇게 맞춰져 있어 조금 작게 들립니다), 그래도 넘는 순간은 잘리지 않고 "피크 보호"가 눌러 줍니다.

## 헤드폰 보정
헤드폰은 모델마다 주파수 특성이 달라, 같은 음악도 저음이 많거나 고음이 날카롭게 들립니다. 그 차이를 측정값으로 만든 필터로 바로잡는 기능입니다. 설정 → 재생 → **헤드폰 보정**에서 씁니다(기본 꺼짐).
- **보정 프로필**에서 쓰는 헤드폰을 고르면 바로 적용됩니다. 널리 쓰이는 헤드폰 34종의 **기본 프로필**이 들어 있습니다.
  - 헤드폰: Sennheiser HD 800 S · HD 600 · HD 650 · HD 660S2 · HD 560S · Momentum 4 Wireless, Beyerdynamic DT 770 Pro · DT 990 Pro · DT 1990(밸런스드 패드), AKG K701 · K371 · K712, Audio-Technica ATH-M50x · ATH-R70x, Sony MDR-7506 · WH-1000XM4 · WH-1000XM5, Apple AirPods Max, Bose QuietComfort 45, HIFIMAN Sundara(2020년 이후 패드) · HE400se · Edition XS, Focal Clear · Utopia, Audeze LCD-X(2021) · LCD-2 Classic, Meze 99 Classics, Koss Porta Pro.
  - 이어폰: Sony WF-1000XM4, Samsung Galaxy Buds2 Pro, Etymotic ER2XR, Moondrop Aria, Sennheiser IE 600.
- 기본 프로필의 값은 AutoEq 프로젝트가 oratory1990의 측정으로 계산해 공개한 것(Harman 목표 곡선 기준)을 고치지 않고 그대로 담은 것입니다. 측정에 쓰인 한 대를 기준으로 한 값이라, 같은 모델이라도 제품마다, 그리고 패드 상태나 쓰는 위치에 따라 조금씩 다를 수 있습니다. 이름에 패드나 연식이 적힌 것은 그 구성으로 측정한 값입니다.
- 목록에 없는 헤드폰은 **보정값 파일**을 구해서 넣습니다. AutoEq 프로젝트가 헤드폰 모델별로 만들어 둔 `ParametricEQ.txt`가 널리 쓰입니다(Equalizer APO 형식의 텍스트 파일). 앱은 인터넷에서 가져오지 않습니다.
- **불러오기…**로 파일을 고르면 파일 이름으로 된 프로필이 만들어지고 바로 적용됩니다(`Sennheiser HD 600 ParametricEQ.txt` → "Sennheiser HD 600"). 같은 이름을 다시 불러오면 값이 바뀝니다. 30개까지 둘 수 있습니다. 불러온 프로필은 목록 위쪽 "불러온 프로필"에 나오고, 기본 프로필과 이름이 같으면 불러온 것이 쓰입니다.
- 고른 프로필 아래에 필터 수와 프리앰프가 보입니다. 쓰지 않을 때는 **끔**으로 둡니다. **삭제**는 불러온 프로필만 지웁니다(기본 프로필은 지워지지 않습니다).
- 지원하는 필터는 **PK**(피킹), **LSC**(로우 셸프), **HSC**(하이 셸프)이고, AutoEq의 파일은 이 세 가지만 씁니다. 다른 종류의 필터가 들어 있는 파일은 일부만 적용하지 않고 통째로 불러오지 않습니다(보정이 달라지기 때문입니다).
- 파일의 `Preamp` 값은 필터가 올린 만큼 전체를 낮춰 소리가 넘치지 않게 하는 값입니다. 그래서 켜면 조금 작게 들립니다. 올림이 프리앰프보다 크면 그 사실을 알려 주며, 넘는 순간은 "피크 보호"가 눌러 줍니다.
- 필터를 모두 합쳐 어느 주파수든 12dB보다 크게 올리는 파일은, 프리앰프를 그만큼 낮춰 적용합니다(잘못 만든 파일로 갑자기 큰 소리가 나지 않게). 실제 보정 파일은 이 한도에 닿지 않습니다.
- 이퀄라이저 다음, 크로스피드 앞에서 적용되고, 이퀄라이저와 함께 쓸 수 있습니다(보정은 헤드폰에 맞추는 것, 이퀄라이저는 취향). 바꿀 때 소리가 튀지 않게 부드럽게 넘어갑니다.
- 켜면 소리는 원본과 달라집니다. 신호 경로에 "헤드폰 보정"과 프로필 이름이 나옵니다. 스피커로 들을 때는 꺼 두세요.

## 헤드폰 크로스피드
설정 → 재생 → **헤드폰**에서 켭니다(기본 꺼짐).
- 한쪽 채널의 저음을 반대쪽에도 조금 섞어, 헤드폰으로 들을 때도 스피커 앞에 앉은 것처럼 만듭니다. 악기가 한쪽에만 몰린 옛 녹음에서 피로를 줄여 줍니다.
- **약하게 · 보통 · 강하게** 가운데 고릅니다. 가운데에서 나는 소리(보컬 등)는 거의 달라지지 않습니다.
- 스피커로 들을 때는 꺼 두세요.

## VU 미터
오른쪽 위의 미터 모양 버튼이나 ⌘⇧U(보기 → VU 미터 보기/가리기)로 엽니다. 재생 막대 위에 왼쪽·오른쪽 채널의 아날로그 미터가 나란히 나타나 재생 중인 음악의 레벨을 바늘로 보여 줍니다.
- 두 미터 사이의 **스펙트럼 표시**는 저음(왼쪽)부터 고음(오른쪽)까지 지금 어떤 소리가 나고 있는지를 막대로 보여 줍니다. 아래 숫자는 주파수(Hz)입니다.
- 미터 양옆에는 지금 재생 중인 곡의 **소스**(파일 형식)와 **출력**(장치, 샘플레이트, 처리 내용)이 표시됩니다. 대기열이나 곡 정보 패널과 함께 열어 둘 수 있습니다.
- 미터 띠의 위쪽 가장자리를 끌면 미터 크기를 바꿀 수 있습니다.
- 눈금은 −20에서 +3 VU까지이고 0 위는 빨간 구간입니다. 요즘 음반은 대체로 0 근처에서, 조용한 녹음은 −10 근처에서 움직입니다.
- 0 VU는 실효값 −11dBFS(최대 진폭 −8dBFS 사인파)에 해당합니다. 샘플이 풀스케일에 닿으면 PEAK 램프가 켜집니다.
- 바늘은 음악 자체의 레벨을 따르므로 앱 볼륨을 줄이거나 음소거해도 움직입니다. 음량 보정을 켜면 보정된 레벨이 보입니다.
- 일시정지하면 바늘이 천천히 왼쪽 끝으로 돌아갑니다.

## 출력 품질
DAC나 좋은 헤드폰으로 들을 때 쓰는 선택 사항입니다(설정 → 재생). 세 가지 모두 처음에는 꺼져 있고, 꺼 두면 OnEum은 장치 설정을 전혀 바꾸지 않습니다.

| 설정 | 하는 일 | 알아 둘 점 |
|---|---|---|
| **곡의 샘플레이트로 출력** | 곡마다 장치를 그 곡의 샘플레이트(44.1kHz, 96kHz …)로 맞춰, 변환(리샘플링) 없이 내보냅니다. 장치가 지원하지 않는 샘플레이트는 그 정수배, 없으면 바로 위, 그것도 없으면 장치의 가장 높은 샘플레이트로 맞춰 변환합니다. | 샘플레이트가 다른 곡으로 넘어갈 때는 장치를 바꾸는 동안 1초 안쪽으로 끊깁니다. 같은 샘플레이트의 곡(같은 앨범)은 끊김 없이 이어집니다. 장치 설정은 다른 앱에도 적용됩니다. |
| **독점 출력** | 재생하는 동안 OnEum만 그 장치를 씁니다. 알림음이나 다른 앱의 소리가 섞이지 않고, 다른 앱이 장치 설정을 바꾸지 못합니다. | 재생 중에는 다른 앱의 소리가 그 장치로 나오지 않습니다(영상 통화, 브라우저 등). |
| **메모리 재생** | 재생할 파일과 다음 곡을 미리 메모리에 올립니다. 외장 드라이브가 잠들거나 네트워크 폴더가 느려져도 재생이 끊기지 않습니다. | 재생 중인 파일 크기만큼(다음 곡 포함 최대 두 파일) 메모리를 씁니다. 1GB가 넘는 파일은 평소처럼 디스크에서 읽습니다. |

- 장치 설정을 바꾼 경우, 대기열이 끝나거나 정지하거나 30초 넘게 일시정지하면 **원래 설정으로 되돌리고 독점도 풉니다.** 앱을 종료할 때도 같습니다.
- 지금 어떻게 재생되고 있는지는 곡 정보 패널(⌘I)의 **신호 경로**와 미터 덱의 **출력**·**처리**에서 볼 수 있습니다. 예: `출력 DAC · 96,000 Hz · 24 bit · 독점`, `처리: 없음`.
  신호 경로가 "원본 그대로"이면(미터 덱의 "처리"가 "없음"이면) 앱은 파일의 샘플을 바꾸지 않고 그대로 내보냅니다. 앱 볼륨을 100%보다 낮추거나 음량 보정·이퀄라이저를 켜면 그 내용이 표시됩니다.
- 샘플레이트 변환이 필요할 때는 20kHz까지 평탄하게 변환합니다. 음량을 꽉 채워 만든 음원을 변환하거나 MP3·AAC를 재생할 때 최대 음량을 넘는 순간이 생기면 "피크 보호"가 그 순간만 눌러 줍니다.
- 앱 볼륨은 100%로 두고 DAC나 앰프에서 음량을 조절하면 샘플을 건드리지 않습니다.

## 파일 검사
설정 → 라이브러리의 **파일 검사**에서 **검사**를 누르면 음악 파일을 끝까지 읽어 확인합니다. 파일은 읽기만 하며, 결과는 앱의 데이터베이스에 남고 파일이 바뀌면 그 파일만 다시 검사합니다.
- **무결성**: 끝까지 디코드되는지, FLAC이면 파일에 든 MD5(원래 오디오의 검사값)와 같은지, 길이가 정확히 적히는 형식(FLAC·ALAC·WAV·AIFF·DSD)은 끝이 잘리지 않았는지 봅니다. MP3는 적힌 길이를 믿을 수 없어 끝이 잘린 것은 가려내지 못합니다.
- **다이내믹 레인지(DR)**: 음악의 큰 소리와 평균 소리의 차이입니다. 클수록 덜 압축된 녹음입니다. dr.loudness-war.info에 공개된 방식으로 계산하며, 다른 측정기와 1 정도 다를 수 있습니다.
- **트루 피크**: 샘플 사이의 파형까지 포함한 가장 높은 레벨(dBTP)입니다. 0을 넘으면 아날로그로 바꿀 때 잘릴 수 있습니다.
- 결과는 곡 정보와 검색(`check:damaged`, `dr:<8`)에 쓰이고, **손상된 곡 보기**로 손상된 파일만 모아 봅니다. **지우기**는 결과를 모두 지웁니다.

## Apple Music에서 옮겨 오기
Apple Music에서 **파일 ▸ 보관함 ▸ 보관함 내보내기…**로 XML 파일을 저장한 뒤, 설정 → 라이브러리의 **Apple Music 보관함 → 가져오기…**에서 그 파일을 고릅니다.
- 라이브러리에 있는 곡(파일 위치로 찾음)에 재생 횟수·마지막 재생·추가한 날짜를 옮기고, 좋아요한 곡은 즐겨찾기가 됩니다. 재생 횟수는 더하지 않고 큰 쪽을 남기므로 여러 번 가져와도 늘지 않습니다.
- 직접 만든 플레이리스트를 만듭니다(스마트 플레이리스트와 폴더는 빼고). 같은 이름의 목록이 이미 있으면 이름 뒤에 "(Apple Music)"이 붙고, 전에 가져온 것과 같은 목록은 다시 만들지 않습니다.
- 라이브러리에 없는 곡은 추가하지 않고 개수만 알려 줍니다. 음악 파일은 바꾸지 않습니다.

## 설정 (⌘,)
오른쪽 위 톱니바퀴 버튼으로도 엽니다. Esc, 닫기(×) 버튼, 창 바깥 클릭으로 닫습니다. 바꾼 내용은 바로 적용되고 저장됩니다.
- **일반**: 언어(시스템/한국어/English), 화면 모드(시스템/밝게/어둡게), 포맷 열 표시.
- **라이브러리**: 음악 폴더마다 곡 수와 마지막 스캔 시각이 보입니다. 돋보기 버튼은 Finder에서 폴더를 열고, 휴지통 버튼은 폴더를 라이브러리에서 제거합니다(확인을 묻고, 원본 파일은 그대로입니다). **음악 폴더 추가**, **다시 스캔**. 그 아래에 파일 검사와 Apple Music에서 옮겨 오기가 있습니다.
- **재생**: 위에서부터 출력 장치(지금 쓰고 있는 장치와 샘플레이트 표시), 출력 품질, 음량 보정과 태그 없는 곡 분석, 재생 순서(앨범 단위 셔플, 긴 곡 이어 듣기), 이퀄라이저, 헤드폰 크로스피드, 헤드폰 보정, 라디오.
- **단축키**: 키보드 단축키 모음.
- **정보**: 버전, 사용 안내 열기, 로그 폴더·데이터 폴더 보기, 오픈 소스 라이선스. 라이선스의 **보기**를 누르면 그 아래에 구성 요소 목록이 표로 펼쳐지고, 출처 주소를 누르면 브라우저에서 열립니다.

## 지원하는 파일
MP3, MP2(.mp2), FLAC, WAV(ADPCM 포함), AIFF, ALAC(.m4a), AAC(.m4a), Ogg Vorbis(.ogg), DSD(.dsf, .dff), Matroska·WebM 오디오(.mka, .webm).
- **곡 사이**: FLAC·WAV·AIFF·ALAC·MP3·AAC는 앨범의 곡 사이가 끊김 없이 이어집니다. AAC는 파일에 적힌 인코더 지연 정보(편집 목록, 또는 Apple의 gapless 정보)를 따라 앞뒤의 무음을 걷어 냅니다. Ogg Vorbis는 파일에 기록된 길이대로 재생하며, 일부 인코더로 만든 파일은 곡 사이에 아주 짧은 틈이 남을 수 있습니다.
- **DSD**: DSF와 DSDIFF(.dff), DSD64부터 DSD512까지. 대부분의 플레이어처럼 PCM(88.2kHz, 48kHz 계열은 96kHz)으로 바꿔 재생하므로 음량 보정·이퀄라이저·미터·샘플레이트 맞춤 출력이 그대로 됩니다. 변환 필터는 20kHz까지 평탄하고, DSD가 고음역 위로 밀어 둔 잡음을 걸러 냅니다. 레벨은 더하지 않아 SACD의 기준 레벨(0dB)이 −6dBFS로 나오므로 CD보다 작게 들릴 수 있습니다(음량 보정의 "태그 없는 곡 분석"이 맞춰 줍니다). 앨범의 DSD 곡들은 앞 곡의 끝과 다음 곡의 처음을 이어서 변환해 끊김 없이 이어집니다. DSD를 그대로 DAC로 보내는 방식(DoP·네이티브)과 DST로 압축된 .dff는 지원하지 않습니다. 곡 정보에는 파일의 DSD 샘플레이트가, 신호 경로에는 "DSD → PCM 변환" 단계가 나옵니다.
- **Matroska·WebM**: 안에 든 FLAC·Vorbis·AAC·MP3·PCM을 재생하고, 파일의 태그를 읽습니다. Opus가 든 WebM은 재생하지 않습니다.
- **CUE 시트**: 앨범 전체가 파일 하나(FLAC·WAV 등)에 들어 있고 옆에 그 파일을 가리키는 `.cue` 파일이 있으면, 시트에 적힌 곡들로 나뉘어 들어갑니다(파일 자체는 따로 나오지 않습니다).
  제목·아티스트·앨범·장르·연도·ReplayGain은 시트에서, 시트에 없는 것은 파일의 태그에서 가져옵니다. 곡은 시트의 `INDEX 01`에서 시작해 다음 곡의 `INDEX 01`에서 끝나고, 이어 들으면 끊김 없이 이어집니다.
  시트의 한글은 UTF-8과 EUC-KR 모두 읽습니다. 시트에 적힌 파일 이름이 실제 이름과 대소문자나 한글 자모 분리만 달라도 그 파일을 찾습니다. 시트가 `.wav`를 가리키는데 같은 이름의 `.flac`만 있으면(변환한 경우) 그것을 씁니다. 그 파일을 Finder에서 열면 시트의 곡들이 열립니다. 시트가 파일보다 긴 음반을 가리키면 파일 안에 있는 곡만 들어가고, 곡이 하나도 파일 안에 없으면(다른 디스크의 시트 등) 파일이 한 곡으로 그대로 들어갑니다. 시트가 생기기 전에 그 파일을 즐겨찾기나 플레이리스트에 넣어 두었다면, 그 자리를 시트의 곡들이 이어받습니다. 시트를 고치거나 지우면 바로(파일 감시) 반영되고, 지우면 파일이 한 곡으로 돌아옵니다.
  곡마다 파일이 따로 있고 시트가 그 파일들을 가리키는 경우(CD 리핑 프로그램이 흔히 만드는 형태)는 시트를 쓰지 않고 파일을 그대로 넣습니다. 한 파일에 시트가 둘이면 이름순으로 앞의 것을 씁니다.
  파일 검사에서 FLAC의 MD5는 파일 전체의 값이라 시트의 곡에는 대조하지 않습니다(끝까지 디코드되는지는 봅니다). M3U8로 내보내면 시트의 곡은 OnEum이 읽는 경로(`앨범.cue/02`)로 적혀, 다른 플레이어에서는 열리지 않습니다. OnEum에서는 그 플레이리스트를 다시 가져올 수 있습니다(음악 폴더를 아직 넣지 않은 경우에도 시트를 찾아 곡을 등록합니다).
- **고해상도**: 24비트, 96·192kHz 파일을 재생합니다. 장치가 그 샘플레이트를 받으면 그대로, 아니면 장치에 맞춰 변환합니다("출력 품질").
- **모노와 서라운드**: 모노는 양쪽으로, 5.1·7.1 파일(FLAC, WAV, AIFF, ALAC)은 스테레오로 섞어 재생합니다. 앞 왼쪽·오른쪽에 가운데와 서라운드 채널을 조금 줄여 더하고, 저음 전용(LFE) 채널은 빼며, 합친 소리가 최대 음량을 넘지 않게 맞춥니다. 서라운드 그대로 내보내지는 않습니다.
- **재생할 수 없는 것**: 복사 방지(DRM)가 걸린 파일(.m4p 등), Opus, WavPack, DST로 압축된 DSD, 그리고 AAC 가운데 HE-AAC(AAC+)와 5.1 채널 AAC. 이런 파일은 라이브러리에 넣지 않고, 스캔이 끝날 때 "지원하지 않는 파일 몇 개 제외"로 알려 줍니다.
- **태그와 표지**: 제목·아티스트·앨범·트랙 번호·연도·장르·ReplayGain·가사·크레딧과 파일에 든 표지를 읽습니다. 표지가 없으면 같은 폴더의 `cover`·`folder` 이미지를 씁니다. 태그가 없는 파일은 파일 이름으로 보여 줍니다. 예전 한국어 Windows에서 넣은(EUC-KR) 태그도 한글로 읽습니다.

## 문제가 생겼을 때
| 상황 | 설명과 해결 |
|---|---|
| 폴더를 추가했는데 "스캔 중"에서 멈춰 있다 | 다운로드·문서·데스크탑 폴더나 외장 드라이브는 macOS가 접근 허용을 묻습니다. 화면의 승인 창에서 **허용**을 누르세요. 거부했다면 시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더에서 OnEum을 허용한 뒤 설정 → 라이브러리에서 다시 스캔하세요. |
| 폴더에 있는 파일이 목록에 나오지 않는다 | 지원하지 않는 형식입니다(Opus, WavPack, HE-AAC, 5.1 AAC, DST 압축 DSD, DRM 파일 등 — "지원하는 파일"). 스캔이 끝날 때 뜨는 알림에 제외된 개수가 나옵니다. |
| 곡이 흐리게 보이고 ⚠ 표시가 있다 | 파일을 찾을 수 없습니다. 외장 드라이브를 다시 연결하거나 파일을 원래 위치로 돌려놓으면 자동으로 돌아옵니다. 이름만 바꾸거나 같은 폴더 안에서 옮긴 파일은 다음 스캔 때 다시 연결됩니다. |
| "건너뛰었습니다" 알림 | 그 곡을 재생할 수 없어 다음 곡으로 넘어갔습니다. 알림에 이유(파일 없음, 손상, 지원하지 않는 형식)가 나옵니다. |
| "출력 장치 연결이 끊겨 일시정지했습니다" | 헤드폰이나 DAC가 분리되었습니다. 갑자기 스피커로 소리가 나지 않도록 멈춘 것입니다. **기본 장치로 재생**을 누르거나 장치를 다시 연결한 뒤 재생하세요. |
| "출력 장치가 응답하지 않아 재생을 제어할 수 없습니다" | 출력 장치(또는 그 드라이버)가 멈춰 있습니다. 장치를 다시 연결하거나 다른 장치를 고른 뒤 OnEum을 다시 시작하세요. 종료에는 몇 초가 걸릴 수 있습니다. |
| 선택한 출력 장치가 없다 | 설정 → 재생에서 "시스템 기본 장치"나 다른 장치를 고르세요. |
| OnEum을 재생하는 동안 다른 앱에서 소리가 나지 않는다 | 설정 → 재생 → **독점 출력**이 켜져 있습니다. 끄거나, OnEum을 정지하면(또는 30초 넘게 일시정지하면) 다른 앱이 장치를 다시 씁니다. |
| 곡이 바뀔 때 잠깐 끊긴다 | **곡의 샘플레이트로 출력**이 켜져 있고 두 곡의 샘플레이트가 다르면 장치를 바꾸느라 잠깐 끊깁니다. 끄면 끊기지 않는 대신 장치의 샘플레이트로 변환해 재생합니다. |
| 음량 보정을 켰는데 어떤 곡은 여전히 크거나 작다 | 그 곡에 보정 값이 없습니다(곡 정보의 ReplayGain이 "없음"). 설정 → 재생 → **태그 없는 곡 분석**을 실행하세요. 값이 있는데도 다르게 들리면 예전 방식의 태그일 수 있습니다("음량 보정"). |
| 곡이 한 곡만 나오고 멈췄다 | **현재 곡이 끝나면 정지**가 켜져 있었습니다(볼륨 옆의 "곡 끝에 정지" 표시). 재생을 누르면 다음 곡부터 이어집니다. |
| 듣는 중에 소리가 줄어들며 멈췄다 | **잠자기 타이머**의 시간이 다 됐습니다. 재생을 누르면 멈춘 자리에서 원래 볼륨으로 이어집니다. |
| 스마트 플레이리스트가 비어 있다 | 조건에 맞는 곡이 지금은 없습니다. 오른쪽 클릭 → **검색 조건 고치기**로 조건을 확인하세요. 알아볼 수 없는 값(`year:abc`, `fav:어쩌면`)이 있으면 아무것도 찾지 않습니다. |
| 보정값 파일을 불러올 수 없다 | 알림에 이유가 나옵니다. "지원하지 않는 필터"는 PK·LSC·HSC가 아닌 필터가 들어 있다는 뜻이고, "이 줄을 이해할 수 없어"는 그 줄의 형식이 다르다는 뜻입니다(`Filter 1: ON PK Fc 105 Hz Gain -3.5 dB Q 0.70` 꼴이어야 합니다). 그래픽 EQ용 파일(`GraphicEQ.txt`)이 아니라 `ParametricEQ.txt`를 고르세요. |
| 소리가 이상하게 들린다(저음이 많다, 좌우가 좁다) | 이퀄라이저나 헤드폰 보정, 헤드폰 크로스피드가 켜져 있는지 보세요. 곡 정보의 **신호 경로**에 지금 걸려 있는 처리가 모두 나옵니다. |
| 가사가 보이지 않는다 | 파일의 태그에 가사가 없고, 같은 폴더에 곡 파일과 이름이 같은 `.lrc`·`.txt`도 없습니다. 가사 파일의 이름을 곡 파일과 똑같이(확장자만 다르게) 맞추세요. |
| 앨범이 둘로 나뉘어 보인다 | 한 앨범의 파일이 여러 폴더에 흩어져 있고 일부에만 "앨범 아티스트" 태그가 있으면 나뉠 수 있습니다. 태그를 맞추거나 한 폴더에 모으면 합쳐집니다. |
| 제목이나 아티스트가 `°¡»ç`처럼 깨져 보임 | 예전 한국어 Windows에서 태그를 넣은 파일입니다. OnEum은 이런 글자를 한글로 읽습니다. 이전 버전에서 스캔해 깨진 채 남아 있다면 **다시 스캔**(⌘R)하면 바로잡힙니다. 그래도 깨져 보이는 곡은 한국어가 아닌 다른 언어의 옛 인코딩일 수 있습니다. |
| 라이브러리 데이터가 손상되었다는 알림 | 새 라이브러리를 만들었습니다. 음악 폴더를 다시 추가하세요. 손상된 파일은 `~/Library/Application Support/OnEum/`에 보관됩니다. |

## 데이터 위치
- 라이브러리와 설정: `~/Library/Application Support/OnEum/` — 곡 목록, 즐겨찾기, 재생 횟수, 플레이리스트와 스마트 플레이리스트, 대기열, 앱이 측정한 음량, 이퀄라이저 프리셋, 헤드폰 보정 프로필, 고른 열이 여기에 있습니다. 이 폴더를 지우면 처음 상태로 돌아가고, 음악 파일에는 영향이 없습니다. 같은 Mac의 다른 사용자 계정은 이 폴더를 읽을 수 없습니다.
- 앨범 이미지 캐시: `~/Library/Caches/OnEum/` (지워도 됩니다. 다시 만들어집니다)
- 로그: `~/Library/Logs/OnEum/oneum.log`
- 설정 → 정보에서 데이터 폴더와 로그 폴더를 바로 열 수 있습니다.
