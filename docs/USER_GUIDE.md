# OnEum 사용 안내

## OnEum이라는 이름
**OnEum**은 우리말 **온음**을 로마자로 적은 이름이고, "온음"이라고 읽습니다.
- **온**은 "온 세상", "온종일"처럼 '모든, 온전한'을 뜻하는 우리말이고 **음(音)**은 소리입니다. 가지고 있는 음악을 빠짐없이, 있는 그대로 **온전하게** 듣는다는 뜻입니다. 파일을 바꾸지 않고, 곡 사이를 끊지 않고, 소리에 손대는 처리는 사용자가 켠 것만 한다는 이 프로그램의 원칙이 여기서 나왔습니다.
- 음악에서 **온음**은 반음 둘을 합친 음정(whole tone)이고, 온음표는 가장 길게 이어지는 음표입니다.
- 영어 **on**(켜다)과도 겹칩니다. 폴더만 추가하면 음악이 바로 켜집니다.

## 시작하기
1. OnEum을 열고 **음악 폴더 추가**를 누릅니다(또는 음악 폴더를 창이나 Dock 아이콘에 끌어다 놓습니다).
2. 폴더 안의 음악이 목록에 나타나기 시작합니다. 스캔이 끝나기를 기다릴 필요 없이 곡을 **더블클릭**하면 재생됩니다.
3. 폴더는 여러 개 추가할 수 있습니다. 파일을 새로 넣거나 지우면 목록이 자동으로 갱신됩니다.

OnEum은 음악 파일을 읽기만 합니다. 파일이나 태그를 바꾸거나 지우지 않습니다.

이 안내는 메뉴 막대의 **도움말 → OnEum 사용 안내**에서 언제든 다시 열 수 있습니다. 왼쪽 목차를 누르면 그 항목으로 이동하고, Esc로 닫습니다.

## 화면
- **왼쪽**: 모든 곡 · 앨범 · 아티스트 · 즐겨찾기 · 최근 재생, 그리고 플레이리스트.
- **가운데**: 곡 목록이나 앨범 표지. 열 제목을 누르면 정렬됩니다(다시 누르면 반대로, 한 번 더 누르면 원래대로).
- **오른쪽**(위쪽 버튼으로 열기): 재생 대기열 또는 곡 정보.
- **아래**: 지금 재생 중인 곡, 이전/재생/다음, 셔플, 반복, 재생 위치, 볼륨.

## 듣기
- 곡을 더블클릭하면 지금 보이는 목록 전체가 대기열이 되고 그 곡부터 재생됩니다.
- 곡을 오른쪽 클릭하면 **다음에 재생**, **대기열 끝에 추가**, **플레이리스트에 추가**, **즐겨찾기**, **Finder에서 보기**, **곡 정보**를 쓸 수 있습니다.
- ⌘클릭이나 ⇧클릭으로 여러 곡을 고를 수 있습니다. ⌘A는 전체 선택입니다. ↑↓로 이동하고 ⇧↑↓로 범위를 늘리거나 줄입니다.
- 같은 동작이 메뉴 막대의 **곡** 메뉴에도 있습니다. 선택한 곡에 적용되고, 선택이 없으면 재생 중인 곡에 적용됩니다.
- 앨범 보기에서 표지에 포인터를 올리면 나오는 ▶ 버튼으로 앨범을 바로 재생합니다.
- 곡 목록을 한 번 클릭한 뒤 글자를 치면 그 글자로 시작하는 곡으로 바로 이동합니다.
- 재생 막대 오른쪽의 시간을 클릭하면 전체 길이와 남은 시간이 번갈아 나옵니다.
- **이전 곡** 버튼은 3초 넘게 들은 상태에서는 지금 곡을 처음부터, 그 전에는 앞 곡으로 갑니다.
- **반복**은 끔 → 전체 → 한 곡 순서로 바뀝니다. 한 곡 반복 중에도 다음/이전 버튼은 다른 곡으로 넘어갑니다.
- **셔플**을 켜면 대기열이 섞이고, 끄면 원래 순서로 돌아옵니다.
- 창을 닫아도(⌘W) 음악은 계속 나옵니다. Dock의 OnEum 아이콘을 누르면 창이 다시 열립니다. 끝내려면 ⌘Q.
- 다시 실행하면 대기열과 듣던 위치가 그대로 돌아옵니다. 소리는 재생 버튼을 눌러야 납니다.

## 검색
- 위쪽 검색 칸(⌘F)에 입력하면 제목·아티스트·앨범에서 바로 찾습니다. Esc로 지웁니다.
- 일부만 입력해도 됩니다: `이유` → 아이유, `bea` → The Beatles.
- 한글 자음만 입력하면 초성으로 찾습니다: `ㅇㅇㅇ` → 아이유.
- 띄어 쓴 단어는 모두 포함된 곡만 나옵니다.

## 대기열
- 오른쪽 위 목록 버튼(⌘U)으로 엽니다. 항목을 끌어서 순서를 바꾸거나, 오른쪽 클릭으로 위/아래 이동·제거할 수 있습니다.
- 항목을 더블클릭하면 그 곡으로 건너뜁니다.
- 곡이나 앨범을 대기열 패널(또는 닫혀 있을 때는 오른쪽 위 목록 버튼)로 끌어다 놓으면 대기열 끝에 추가됩니다.
- 대기열 항목을 한 번 클릭한 뒤에는 키보드로도 다룹니다: ↑↓ 이동, Return 재생, Delete 제거, ⌥↑/⌥↓ 순서 바꾸기.

## 플레이리스트
- 사이드바의 **+** 또는 ⌘N으로 만듭니다. 곡을 오른쪽 클릭 → **플레이리스트에 추가**.
- 플레이리스트 이름을 더블클릭(또는 오른쪽 클릭 → 이름 변경)하면 이름을 바꿉니다.
- 오른쪽 클릭 → **M3U8로 내보내기**, 파일 메뉴 → **플레이리스트 가져오기**(또는 `.m3u8` 파일을 OnEum으로 열기).
- 곡이나 앨범을 사이드바의 플레이리스트로 끌어다 놓아도 추가됩니다. "플레이리스트" 제목에 놓으면 새 플레이리스트가 됩니다.
- 플레이리스트 안에서 곡을 끌어 순서를 바꿉니다.
- 열려 있는 플레이리스트는 파일 메뉴에서도 이름 변경·내보내기·삭제할 수 있습니다.
- 곡을 고르고 Delete를 누르면 플레이리스트에서 뺍니다. 아래 알림 줄의 **실행 취소**로 되돌릴 수 있습니다.
- 플레이리스트를 지워도 음악 파일은 지워지지 않습니다.

## 설정 (⌘,)
오른쪽 위 톱니바퀴 버튼으로도 엽니다. Esc, 닫기(×) 버튼, 창 바깥 클릭으로 닫습니다. 바꾼 내용은 바로 적용되고 저장됩니다.
- **일반**: 언어(시스템/한국어/English), 화면 모드(시스템/밝게/어둡게), 포맷 열 표시.
- **라이브러리**: 음악 폴더마다 곡 수와 마지막 스캔 시각이 보입니다. 돋보기 버튼은 Finder에서 폴더를 열고, 휴지통 버튼은 폴더를 라이브러리에서 제거합니다(확인을 묻고, 원본 파일은 그대로입니다). **음악 폴더 추가**, **다시 스캔**.
- **재생**: 출력 장치(지금 쓰고 있는 장치와 샘플레이트 표시), 출력 품질, 음량 보정(ReplayGain). 프리앰프 슬라이더는 더블클릭하면 0dB로 돌아갑니다.
- **단축키**: 키보드 단축키 모음.
- **정보**: 버전, 사용 안내 열기, 로그 폴더·데이터 폴더 보기, 오픈 소스 라이선스. 라이선스의 **보기**를 누르면 그 아래에 구성 요소 목록이 표로 펼쳐지고, 출처 주소를 누르면 브라우저에서 열립니다.
  - 음량 보정은 파일에 이미 들어 있는 ReplayGain 태그만 사용합니다. 태그가 없는 곡은 그대로 재생합니다.
  - "클리핑 방지"를 켜 두면 보정 때문에 소리가 찌그러지지 않도록 이득을 제한합니다. 꺼 두어도 최대 음량을 넘는 순간은 잘리지 않고 "피크 보호"가 눌러 줍니다.

## 이퀄라이저 (⌘E)
위쪽의 슬라이더 모양 버튼이나 **보기 → 이퀄라이저**, 설정 → 재생의 **이퀄라이저 → 열기**로 엽니다. 버튼은 이퀄라이저가 소리를 바꾸고 있는 동안 강조색으로 켜집니다.
- **대역 10개**(32Hz ~ 16kHz, 한 옥타브 간격)와 **프리앰프**를 ±12dB 범위에서 0.5dB 단위로 조절합니다. 끌거나 클릭해서 맞추고, **더블클릭하면 0dB**로 돌아갑니다. 슬라이더에 초점이 있으면 ↑↓로 한 칸씩 움직입니다.
- 위쪽 곡선은 지금 값이 주파수별로 소리를 얼마나 올리고 내리는지 보여 줍니다. 각 대역은 제 슬라이더 바로 위에 있습니다.
- **프리셋**: 플랫, 저음 강화, 저음 줄이기, 고음 강화, 보컬, 라우드니스(작은 음량용), 팝, 록, 재즈, 클래식, 일렉트로닉, 어쿠스틱이 들어 있습니다. 고르면 바로 켜집니다. 슬라이더를 움직이면 "사용자 설정"으로 바뀝니다.
- **내 프리셋**: 이름을 적고 **내 프리셋으로 저장**을 누르면 지금 값이 그 이름으로 저장되어 프리셋 목록 아래쪽에 나타납니다(40개까지). 같은 이름으로 다시 저장하면 값이 바뀝니다. 내 프리셋을 고른 상태에서는 **이 프리셋 삭제**가 보입니다.
- 오른쪽 위의 스위치로 켜고 끕니다. 꺼 두거나 모든 값이 0dB이면 소리를 전혀 건드리지 않습니다.
- 조절한 소리는 1초 안에 들립니다(미리 디코드해 둔 만큼 지나야 합니다). 값이 바뀔 때 소리가 튀지 않도록 부드럽게 옮겨 갑니다.
- 대역을 올리면 소리가 최대 음량을 넘을 수 있습니다. 올린 만큼 프리앰프를 내려 두면 넘지 않고(기본 프리셋은 그렇게 맞춰져 있어 조금 작게 들립니다), 그래도 넘는 순간은 잘리지 않고 "피크 보호"가 눌러 줍니다.

## 신호 경로
곡 정보 패널(⌘I)의 **신호 경로**는 재생 중인 곡이 파일에서 출력 장치까지 가는 동안 앱이 하는 일을 순서대로 보여 줍니다. 예: `소스 FLAC · 44,100 Hz · 16 bit → 리샘플링 44,100 → 48,000 Hz → 이퀄라이저 록 → 출력 MacBook Pro 스피커 · 48,000 Hz`.
- 오른쪽 위의 한마디가 요약입니다. **원본 그대로**: 앱이 샘플을 바꾸지 않습니다. **사용자 조정**: 음량 보정·이퀄라이저·크로스피드·앱 볼륨처럼 직접 켠 기능이 소리를 바꾸고 있습니다. **변환**: 이 장치로 내보내려고 샘플레이트·채널·비트 깊이를 바꾸고 있습니다. 한마디에 마우스를 올리면 설명이 나옵니다.
- 점의 색이 단계의 종류입니다: 보라색은 사용자가 켠 조정, 청록색은 장치에 맞춘 변환, 호박색은 피크 보호.
- "원본 그대로"는 앱 안에서의 이야기입니다. 그 뒤의 운영체제·드라이버·DAC 구간은 앱이 확인할 수 없습니다.

## 다시 듣기, 가사, 라디오
- **다시 듣기**(왼쪽 목록): 위쪽의 네 탭으로 **최근 재생**, **최근 추가**(라이브러리에 새로 들어온 순), **많이 들은 곡**, **오래 안 들은 곡**(들은 적이 있지만 30일 넘게 듣지 않은 곡, 오래된 순)을 봅니다. 각 300곡까지 보여 줍니다.
- **가사**: 파일의 태그에 가사가 들어 있거나, 곡과 같은 이름의 `.lrc`·`.txt` 파일이 같은 폴더에 있으면 곡 정보 패널(⌘I) 아래쪽에 보여 줍니다. `.lrc`의 시간 표시는 떼고 글만 보여 줍니다. 가사를 인터넷에서 찾아오지는 않습니다.
- **라디오**(설정 → 재생, 기본 꺼짐): 켜 두면 대기열의 마지막 곡이 시작될 때 그 곡과 어울리는 곡 다섯 곡을 라이브러리에서 골라 대기열 끝에 더합니다. 그래서 음악이 끊기지 않습니다. 장르·아티스트·연도가 가까운 곡을 먼저 고르고, 방금(2시간 안에) 들은 곡과 같은 아티스트가 세 곡 이상 이어지는 것은 피합니다. 반복 재생이 켜져 있으면 동작하지 않습니다. 더해진 곡은 대기열에서 평소처럼 지우거나 옮길 수 있습니다.
- **헤드폰 크로스피드**(설정 → 재생, 기본 꺼짐): 한쪽 채널의 저음을 반대쪽에도 조금 섞어, 헤드폰으로 들을 때도 스피커 앞에 앉은 것처럼 만듭니다. 악기가 한쪽에만 몰린 옛 녹음에서 피로를 줄여 줍니다. 약하게·보통·강하게 가운데 고르고, 스피커로 들을 때는 꺼 두세요.

## VU 미터
오른쪽 위의 미터 모양 버튼이나 ⌘⇧U(보기 → VU 미터 보기/가리기)로 엽니다. 재생 막대 위에 왼쪽·오른쪽 채널의 아날로그 미터가 나란히 나타나 재생 중인 음악의 레벨을 바늘로 보여 줍니다.
- 두 미터 사이의 **스펙트럼 표시**는 저음(왼쪽)부터 고음(오른쪽)까지 지금 어떤 소리가 나고 있는지를 막대로 보여 줍니다. 아래 숫자는 주파수(Hz)입니다.
- 미터 양옆에는 지금 재생 중인 곡의 **소스**(파일 형식)와 **출력**(장치, 샘플레이트, 처리 내용)이 표시됩니다. 대기열이나 곡 정보 패널과 함께 열어 둘 수 있습니다.
- 미터 띠의 위쪽 가장자리를 끌면 미터 크기를 바꿀 수 있습니다.
- 눈금은 −20에서 +3 VU까지이고 0 위는 빨간 구간입니다. 요즘 음반은 대체로 0 근처에서, 조용한 녹음은 −10 근처에서 움직입니다.
- 0 VU는 실효값 −11dBFS(최대 진폭 −8dBFS 사인파)에 해당합니다. 샘플이 풀스케일에 닿으면 PEAK 램프가 켜집니다.
- 바늘은 음악 자체의 레벨을 따르므로 앱 볼륨을 줄이거나 음소거해도 움직입니다. 음량 보정(ReplayGain)을 켜면 보정된 레벨이 보입니다.
- 일시정지하면 바늘이 천천히 왼쪽 끝으로 돌아갑니다.

## 출력 품질 (설정 → 재생)
DAC나 좋은 헤드폰으로 들을 때 쓰는 선택 사항입니다. 세 가지 모두 처음에는 꺼져 있고, 꺼 두면 OnEum은 장치 설정을 전혀 바꾸지 않습니다.

| 설정 | 하는 일 | 알아 둘 점 |
|---|---|---|
| **곡의 샘플레이트로 출력** | 곡마다 장치를 그 곡의 샘플레이트(44.1kHz, 96kHz …)로 맞춰, 변환(리샘플링) 없이 내보냅니다. 장치가 지원하지 않는 샘플레이트는 그 정수배, 없으면 바로 위, 그것도 없으면 장치의 가장 높은 샘플레이트로 맞춰 변환합니다. | 샘플레이트가 다른 곡으로 넘어갈 때는 장치를 바꾸는 동안 1초 안쪽으로 끊깁니다. 같은 샘플레이트의 곡(같은 앨범)은 끊김 없이 이어집니다. 장치 설정은 다른 앱에도 적용됩니다. |
| **독점 출력** | 재생하는 동안 OnEum만 그 장치를 씁니다. 알림음이나 다른 앱의 소리가 섞이지 않고, 다른 앱이 장치 설정을 바꾸지 못합니다. | 재생 중에는 다른 앱의 소리가 그 장치로 나오지 않습니다(영상 통화, 브라우저 등). |
| **메모리 재생** | 재생할 파일과 다음 곡을 미리 메모리에 올립니다. 외장 드라이브가 잠들거나 네트워크 폴더가 느려져도 재생이 끊기지 않습니다. | 재생 중인 파일 크기만큼(다음 곡 포함 최대 두 파일) 메모리를 씁니다. 1GB가 넘는 파일은 평소처럼 디스크에서 읽습니다. |

- 장치 설정을 바꾼 경우, 대기열이 끝나거나 정지하거나 30초 넘게 일시정지하면 **원래 설정으로 되돌리고 독점도 풉니다.** 앱을 종료할 때도 같습니다.
- 지금 어떻게 재생되고 있는지는 곡 정보 패널(⌘I)의 **신호 경로**와 미터 덱의 **출력**·**처리**에서 볼 수 있습니다. 예: `출력 DAC · 96,000 Hz · 24 bit · 독점`, `처리: 없음`.
  신호 경로가 "원본 그대로"이면(미터 덱의 "처리"가 "없음"이면) 앱은 파일의 샘플을 바꾸지 않고 그대로 내보냅니다. 앱 볼륨을 100%보다 낮추거나 음량 보정을 켜면 그 내용이 표시됩니다.
  "디더"는 16·24비트 장치로 내보낼 때 반올림 때문에 생기는 왜곡을 막으려고 아주 작은 잡음을 더했다는 뜻이며, 샘플을 그대로 내보낼 때는 넣지 않습니다.
  "피크 보호"는 그 곡에서 최대 음량(0dBFS)을 넘는 순간이 있어, 소리가 잘려 찌그러지지 않도록 그 순간에만 음량을 살짝 낮췄다는 뜻입니다.
  음량을 꽉 채워 만든 음원을 다른 샘플레이트로 변환하거나 MP3·AAC를 재생할 때 생기며, 넘는 순간이 없는 곡에는 아무것도 하지 않습니다.
- 앱 볼륨은 100%로 두고 DAC나 앰프에서 음량을 조절하면 샘플을 건드리지 않습니다.

## 지원하는 파일
MP3, MP2(.mp2), FLAC, WAV, AIFF, ALAC(.m4a), AAC(.m4a), Ogg Vorbis(.ogg).
FLAC·WAV·AIFF·ALAC·MP3는 앨범의 곡 사이가 끊김 없이 이어집니다. AAC와 Ogg Vorbis는 재생은 되지만 곡 사이에 아주 짧은 틈이 생길 수 있습니다.
복사 방지(DRM)가 걸린 파일(.m4p 등)과 Opus는 재생할 수 없습니다.

## 문제가 생겼을 때
| 상황 | 설명과 해결 |
|---|---|
| 폴더를 추가했는데 "스캔 중"에서 멈춰 있다 | 다운로드·문서·데스크탑 폴더나 외장 드라이브는 macOS가 접근 허용을 묻습니다. 화면의 승인 창에서 **허용**을 누르세요. 거부했다면 시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더에서 OnEum을 허용한 뒤 설정 → 라이브러리에서 다시 스캔하세요. |
| 곡이 흐리게 보이고 ⚠ 표시가 있다 | 파일을 찾을 수 없습니다. 외장 드라이브를 다시 연결하거나 파일을 원래 위치로 돌려놓으면 자동으로 돌아옵니다. 이름만 바꾸거나 같은 폴더 안에서 옮긴 파일은 다음 스캔 때 다시 연결됩니다. |
| "건너뛰었습니다" 알림 | 그 곡을 재생할 수 없어 다음 곡으로 넘어갔습니다. 알림에 이유(파일 없음, 손상, 지원하지 않는 형식)가 나옵니다. |
| "출력 장치 연결이 끊겨 일시정지했습니다" | 헤드폰이나 DAC가 분리되었습니다. 갑자기 스피커로 소리가 나지 않도록 멈춘 것입니다. **기본 장치로 재생**을 누르거나 장치를 다시 연결한 뒤 재생하세요. |
| "출력 장치가 응답하지 않아 재생을 제어할 수 없습니다" | 출력 장치(또는 그 드라이버)가 멈춰 있습니다. 장치를 다시 연결하거나 다른 장치를 고른 뒤 OnEum을 다시 시작하세요. 종료에는 몇 초가 걸릴 수 있습니다. |
| 선택한 출력 장치가 없다 | 설정 → 재생에서 "시스템 기본 장치"나 다른 장치를 고르세요. |
| OnEum을 재생하는 동안 다른 앱에서 소리가 나지 않는다 | 설정 → 재생 → **독점 출력**이 켜져 있습니다. 끄거나, OnEum을 정지하면(또는 30초 넘게 일시정지하면) 다른 앱이 장치를 다시 씁니다. |
| 곡이 바뀔 때 잠깐 끊긴다 | **곡의 샘플레이트로 출력**이 켜져 있고 두 곡의 샘플레이트가 다르면 장치를 바꾸느라 잠깐 끊깁니다. 끄면 끊기지 않는 대신 장치의 샘플레이트로 변환해 재생합니다. |
| 앨범이 둘로 나뉘어 보인다 | 한 앨범의 파일이 여러 폴더에 흩어져 있고 일부에만 "앨범 아티스트" 태그가 있으면 나뉠 수 있습니다. 태그를 맞추거나 한 폴더에 모으면 합쳐집니다. |
| 라이브러리 데이터가 손상되었다는 알림 | 새 라이브러리를 만들었습니다. 음악 폴더를 다시 추가하세요. 손상된 파일은 `~/Library/Application Support/OnEum/`에 보관됩니다. |

## 데이터 위치
- 라이브러리와 설정: `~/Library/Application Support/OnEum/`
- 앨범 이미지 캐시: `~/Library/Caches/OnEum/` (지워도 됩니다. 다시 만들어집니다)
- 로그: `~/Library/Logs/OnEum/oneum.log`
