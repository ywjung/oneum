# OnEum UX 명세

코드와 테스트는 이 문서의 동작 정의를 따른다(`src/playback/queue.rs` 테스트가 각 규칙을 검증).

## 화면 구성
- **왼쪽 사이드바**: 라이브러리(모든 곡 · 앨범 · 아티스트 · 즐겨찾기 · 최근 재생), 플레이리스트 목록, "+ 새 플레이리스트".
- **중앙**: 선택한 보기의 곡 목록(표) 또는 앨범 격자 / 앨범 상세 / 아티스트 목록.
- **오른쪽 패널(선택)**: 재생 대기열 또는 곡 정보. 툴바 버튼으로 열고 닫는다.
- **하단 재생 막대**: 앨범 이미지·제목·아티스트, 이전/재생·일시정지/다음, 셔플, 반복, 탐색 바, 시간, 볼륨.
- **상단**: 검색 필드, 스캔 진행 표시, 대기열/정보 패널 전환.

곡 목록 기본 열: 제목 · 아티스트 · 앨범 · 길이. 앨범 상세에서는 트랙 번호가 앞에 붙는다. 포맷 열은 설정에서 켠다.

## 첫 실행
1. 빈 라이브러리 화면 중앙에 "음악 폴더 추가" 버튼 하나를 가장 크게 보여 준다.
2. 폴더를 고르면 곧바로 스캔을 시작하고 상단에 "스캔 중 · N곡 발견"을 표시한다.
3. 발견된 곡은 스캔이 끝나기 전에도 목록에 나타나고 재생할 수 있다.
4. 설정은 요구하지 않는다.

## 재생 동작 정의
| 상황 | 동작 |
|---|---|
| 곡 더블클릭(또는 Return) | 현재 보이는 목록 전체(정렬·검색 결과 그대로)를 대기열로 바꾸고 그 곡부터 재생한다. 셔플이 켜져 있으면 그 곡을 맨 앞에 두고 나머지를 섞는다. |
| 대기열 패널에서 더블클릭 | 대기열을 바꾸지 않고 그 항목으로 이동해 재생한다. |
| "다음에 재생" | 선택한 곡들을 현재 곡 바로 뒤에 선택 순서대로 넣는다. 대기열이 비어 있으면 넣고 첫 곡을 일시정지 상태로 준비한다. |
| "대기열 끝에 추가" | 선택한 곡들을 대기열 맨 뒤에 넣는다. 셔플 중에도 맨 뒤다. |
| 같은 곡을 여러 번 추가 | 허용. 대기열 항목은 곡 ID와 별개의 항목 ID를 가진다. |
| 현재 재생 곡을 대기열에서 제거 | 다음 항목으로 넘어간다. 재생 중이었으면 계속 재생, 일시정지였으면 일시정지로 준비. 다음 항목이 없으면 정지하고 재생 막대를 비운다. |
| 다음 곡 버튼 | 다음 항목으로. 마지막 항목에서: 반복 끔 → 정지(대기열은 유지), 반복 전체/1곡 → 처음으로. |
| 이전 곡 버튼 | 재생 위치가 3초를 넘었으면 현재 곡을 처음부터. 아니면 이전 항목으로. 첫 항목에서: 반복 끔 → 현재 곡 처음부터, 반복 전체/1곡 → 마지막 항목으로. |
| 곡이 자연스럽게 끝남 | 반복 1곡 → 같은 곡 다시. 그 외 → 다음 항목(gapless 연결). 마지막 항목: 반복 끔 → 정지, 반복 전체 → 처음으로(셔플이면 다시 섞음). |
| 반복 1곡 상태에서 다음/이전 버튼 | 사용자의 명시적 이동이므로 다음/이전 항목으로 간다(반복 전체처럼 끝에서 순환). 반복 1곡 모드는 유지된다. |
| 셔플 켜기 | 현재 곡을 맨 앞에 두고 나머지 대기열을 무작위로 섞는다. 대기열 패널은 실제 재생 순서를 보여 준다. |
| 셔플 끄기 | 대기열을 섞기 전 순서로 되돌린다. 현재 곡은 그대로 재생된다. |
| 셔플 상태에서 이전 곡 | 섞인 재생 순서에서 한 칸 앞, 즉 방금 들은 곡으로 돌아간다(무작위로 다른 곡을 뽑지 않는다). |
| 재생할 수 없는 곡(누락·손상) | 건너뛰고 다음 곡으로. 건너뛴 이유를 하단 알림으로 보여 준다. 10곡(대기열이 더 짧으면 대기열 전체)이 연속으로 실패하면 정지하고 안내한다. |
| Finder에서 파일 열기·끌어다 놓기 | 음악 파일은 라이브러리에 "개별 추가한 곡"으로 등록하고 대기열을 그 파일들로 바꿔 재생한다. 폴더를 끌어다 놓으면 음악 폴더로 추가한다. `.m3u8`은 플레이리스트로 가져온다. |

## 창과 앱 수명
- 창의 닫기 버튼(⌘W)은 **창만 숨긴다.** 재생은 계속된다(음악 앱 관례). 전체 화면에서는 앱을 숨긴다(빈 화면이 남지 않게).
- 창이 숨겨져 있거나 가려져 있어도 Finder에서 연 파일, 메뉴 명령, 재생 상태 처리는 그대로 동작한다.
- Dock 아이콘을 누르면 숨겨진 창이 다시 나타난다.
- ⌘Q는 상태를 저장하고 앱을 끝낸다.
- 재실행하면 대기열·현재 곡·재생 위치·볼륨·셔플/반복을 복원하되 **항상 일시정지 상태**로 시작한다.

## 선택과 컨텍스트 메뉴
- 클릭: 단일 선택. ⌘클릭: 토글. ⇧클릭: 범위 선택. ⌘A: 전체.
- 곡 컨텍스트 메뉴: 재생 · 다음에 재생 · 대기열 끝에 추가 · 플레이리스트에 추가 ▸ · 즐겨찾기 · Finder에서 보기 · (플레이리스트 안에서) 플레이리스트에서 제거 · 곡 정보.
- 대기열 항목: 위/아래로 이동(드래그 또는 메뉴), 대기열에서 제거, 대기열 비우기.
- **목록 키의 주인**: ↑↓·Return·Delete·⌘A는 마지막으로 클릭한 목록(곡 목록 또는 대기열)에만 적용된다.
  텍스트 필드에 입력 중이거나 Tab으로 버튼에 초점이 가 있으면 그 키는 필드·버튼의 것이다.
- **곡 메뉴**(메뉴 막대): 컨텍스트 메뉴의 동작을 선택한 곡에 적용한다(선택이 없으면 재생 중인 곡).
  마우스 없이, VoiceOver로도 모든 곡 동작에 닿을 수 있게 하기 위함이다.
- 검색으로 걸러진 플레이리스트에서는 위/아래 이동을 쓸 수 없다(보이는 순서가 실제 순서가 아니므로).
- 앨범 표지에 포인터를 올리면 재생 버튼이 나타난다: 버튼은 그 앨범을 재생, 그 밖의 곳은 앨범을 연다.

## 표시 규칙
- 재생 중인 곡: 제목 앞에 재생 표시(▶ / 일시정지 시 ❙❙)와 강조 색. 선택한 곡: 배경 강조. 두 상태는 동시에 구분되어 보인다.
- 사용할 수 없는 곡(누락·드라이브 분리): 흐리게 표시하고 툴팁에 이유를 적는다.
- 긴 제목은 한 줄로 자르고 툴팁으로 전체를 보여 준다. 앨범 이미지가 없으면 중립적인 자리표시 이미지를 쓴다.
- 검색어·선택·스크롤 위치는 보기를 오가도 보기별로 유지된다. 라이브러리가 갱신되어도 선택은 곡 ID 기준으로 유지된다.
- 아이콘만 있는 버튼은 모두 툴팁과 접근성 이름을 가진다.

## 오류와 안내
- 상태 변화(사용자가 시작한 스캔의 완료, 건너뜀, 장치 변경)는 모달이 아니라 하단 알림 줄로 알린다. 파일 변경에 따른 자동 재스캔은 조용히 반영한다. 알림은 원인과 할 수 있는 행동(버튼)을 함께 담는다.
- 파괴적 동작만 확인을 받는다: 음악 폴더 제거, 플레이리스트 삭제. 문구에 "원본 파일은 삭제되지 않습니다"를 명시한다.
  확인 창에서 Return은 강조된 버튼, Esc는 취소다.
- 되돌릴 수 있는 동작은 묻지 않고 되돌릴 길을 준다: 플레이리스트에서 곡을 제거하면 알림 줄에 [실행 취소]가 8초간 나온다.
- 해결될 때까지 남아야 하는 알림(장치 분리, 폴더 권한)은 잠깐 뜨는 알림에 밀려나지 않는다. 잠깐 뜨는 알림이 사라지면 다시 보인다.
- 앱을 시작할 수 없으면(라이브러리를 열 수 없음 등) 이유와 로그 위치를 경고 창으로 보여 준 뒤 끝낸다.
- 출력 장치가 사라지면 일시정지하고 "출력 장치 연결이 끊겼습니다 — [기본 장치로 재생] [설정]"을 보여 준다. 다른 스피커로 자동 전환하지 않는다.

## 검색
- 제목·아티스트·앨범·앨범 아티스트에서 찾는다. 공백으로 나눈 모든 단어가 포함되어야 한다(AND).
- 부분 일치: `이유` → "아이유", `bea` → "The Beatles". 대소문자·전각/반각·NFC/NFD 차이는 무시한다.
- 초성 검색: 검색어가 한글 자음만으로 이루어지면 초성으로 찾는다(`ㅇㅇㅇ` → "아이유").
- 입력할 때마다 즉시 갱신한다.

## 언어와 테마
- 한국어/영어. 기본은 시스템 언어(한국어가 아니면 영어). 설정에서 바꾸면 즉시 반영.
- 테마: 시스템 따르기(기본) / 밝게 / 어둡게.
