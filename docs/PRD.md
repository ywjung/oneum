# OnEum 제품 요구사항 (PRD)

## 한 줄 정의
폴더만 추가하면 바로 듣는, macOS용 오프라인 로컬 음악 플레이어.

## 사용자
- MP3·FLAC·ALAC 등 로컬 음악 파일을 가진 사람
- foobar2000의 재생 품질과 라이브러리 기능은 좋지만 설정과 화면이 어렵다고 느끼는 사람
- 스트리밍 계정 없이 자기 음악을 듣고 싶은 사람

## 원칙
- 기본 동작은 오프라인. 로그인·서버·광고·사용량 수집 없음.
- 음악 파일은 읽기 전용. 태그·파일을 바꾸지 않는다.
- 기본 화면은 단순하게, 고급 기능은 필요한 순간에.
- 검증하지 않은 것을 지원한다고 쓰지 않는다("무손실 출력", "bit-perfect" 표현 금지).

## 지원 환경
- macOS 14 이상을 최소 버전으로 선언(Info.plist). 실제 검증은 macOS 27.2.1에서만 수행.
- Apple Silicon(arm64)만 지원. Intel은 검증 장비가 없어 지원 표기하지 않는다.
- Windows(x86_64)용으로도 빌드된다. 같은 코드에 플랫폼 계층만 다르다. 실제 Windows에서 검증하기 전까지는 "빌드됨"으로만 적고 지원 환경으로 적지 않는다.

## v1.0 범위 (완료 조건)
MVP: 폴더 추가/제거, 하위 폴더 스캔과 진행 표시, MP3·FLAC·WAV 재생, 재생/일시정지/이전/다음,
탐색 바와 앱 볼륨, 곡 목록과 앨범 이미지, 제목·아티스트·앨범 검색, 대기열 확인·편집,
플레이리스트 생성·이름 변경·삭제·곡 추가/제거, 설정·라이브러리 저장, 재시작 시 상태 복원,
밝은/어두운/시스템 테마, 이해하기 쉬운 오류와 빈 화면.

v1.0 추가: 앨범·아티스트 탐색, 즐겨찾기와 최근 재생, 셔플·반복, 다중 선택과 대기열 순서 변경,
검증된 범위의 gapless, ReplayGain 태그 기반 음량 보정(태그 없는 곡은 앱이 음량을 재서 보정 — 파일은 바꾸지 않음), AAC-LC·ALAC·AIFF·Ogg Vorbis,
파일 변경 감지와 증분 스캔, 분리된 외장 드라이브·누락 파일 처리, M3U8 가져오기/내보내기,
출력 장치 선택과 변경 대응, 출력 품질 옵션(곡의 샘플레이트로 출력·독점 출력·메모리 재생, 모두 선택 사항),
미터 덱(아날로그 VU 미터와 스펙트럼 표시), 10밴드 이퀄라이저(기본 프리셋과 내 프리셋), 헤드폰 보정(기본 프로필 33종과 파라메트릭 보정값 파일 불러오기), 헤드폰 크로스피드, 신호 경로 표시,
다시 듣기 목록(최근 추가·많이 들은 곡·오래 안 들은 곡), 가사 표시(태그·`.lrc`, 시간 표시가 있으면 싱크), 태그에 든 크레딧·작품 정보와 장르 보기, 검색의 필드 지정(`artist:`·`year:`·`plays:`·`added:` 등)과 그 검색을 저장하는 스마트 플레이리스트, 목록의 선택 열, 현재 곡이 끝나면 정지, 잠자기 타이머, 라디오(대기열이 끝나면 라이브러리에서 이어 재생), 앱 안에서 보는 사용 안내, 미디어 키와 Now Playing, Finder 열기·드래그 앤 드롭·Finder에서 보기,
한글·영어 UI, 키보드 접근성과 VoiceOver, .app/.dmg, 사용자 안내서·검증 보고서·릴리스 절차.

## 범위 밖 (후속)
태그 편집, ReplayGain 태그 쓰기, CUE, 미니 플레이어, 별점, 파라메트릭 EQ를 화면에서 직접 설계하기(보정값 파일 불러오기는 됨)·룸 보정·컨볼루션, 크로스페이드, 플러그인, CD 리핑·변환,
스트리밍·클라우드·인터넷 라디오, 온라인 메타데이터(약력·리뷰·크레딧·가사 검색), 멀티룸·AirPlay·Chromecast 출력, 원격 조작 앱,
DSD·MQA·Opus·WavPack(디코더 없음), 멀티채널 출력, 업샘플링 필터 선택, bit-perfect 보증, 자동 업데이트. DRM 보호 파일은 재생 불가.

## 완료 판정 흐름
1. 앱 실행 → 음악 폴더 추가  2. 스캔 중 발견된 곡 재생  3. 한글·영어 검색, 앨범 탐색
4. 플레이리스트·대기열 편집  5. 셔플·반복, 이전·다음  6. 미디어 키, Now Playing
7. 종료 후 재실행 시 상태 복원  8. 파일·장치 오류에서 복구  9. 패키징된 앱 설치·실행

## 성능 초기 목표
시작 후 2초 내 조작 가능(구축된 라이브러리, SSD) · 5만 곡 검색 p95 ≤ 200ms · UI 반응 ≤ 100ms ·
재생 시작 p95 ≤ 500ms · 2시간 연속 재생에서 앱 원인 underrun 0 · 정지 화면에서 지속 렌더링 없음.
실측은 docs/TESTING.md에 기록한다.
