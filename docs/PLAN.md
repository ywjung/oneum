## 위험과 대응
| 위험 | 대응 |
|---|---|
| 편집 메뉴와 egui 텍스트 입력 충돌 | 응답 체인 브리지(검증됨) |
| 기본 장치 자동 전환으로 스피커에서 소리 남 | 장치 ID 고정 스트림 + 분리 시 일시정지 |
| MP3 gapless(인코더 지연) | Symphonia gapless 디코드 + 프레임 수 일치 테스트 |
| 한글 부분 검색 | 메모리 부분 일치 + 초성, 5만 곡 실측 |
| Developer ID 없음 | ad-hoc 서명까지. 공증 절차는 문서화하고 검증 대기로 표기 |
| VoiceOver 음성 확인 | 접근성 트리는 자동 확인, 음성은 수동 체크리스트 |
