## Windows에서 다른 점
- **설치**: `OnEum-…-setup.exe`를 실행하면 시작 메뉴에 OnEum이 생깁니다(관리자 권한이 필요 없습니다). 제거는 Windows의 **설정 → 앱 → 설치된 앱**에서 합니다. 제거할 때 라이브러리와 설정도 지울지 묻고, 음악 파일은 건드리지 않습니다. 설치하지 않고 쓰려면 zip 파일을 풀어 `OnEum.exe`를 실행합니다.
- 메뉴 막대는 창 맨 위에 있습니다. 단축키는 Ctrl 키로 누릅니다.
- 창을 닫으면 프로그램이 끝나고 재생도 멈춥니다. 이 안내에서 Dock에 관한 설명은 Windows에는 해당하지 않습니다.
- 음악 파일을 `OnEum.exe`에 끌어다 놓거나 "연결 프로그램"으로 열면 그 파일을 재생합니다.
- 키보드의 미디어 키와 Windows의 미디어 표시(볼륨을 바꿀 때나 작업 표시줄에서 나오는 재생 조작)로 재생·일시정지·이전·다음과 위치 이동을 할 수 있습니다. OnEum이 이미 열려 있을 때 음악 파일을 OnEum으로 열면 새 창을 띄우지 않고 열려 있는 창에서 재생합니다.
- 출력 품질의 **곡의 샘플레이트로 출력**과 **독점 출력**은 macOS에서만 동작합니다. Windows에서는 시스템이 정한 샘플레이트로 맞춰 재생합니다. **메모리 재생**과 VU 미터는 똑같이 쓸 수 있습니다.
- 데이터 위치는 `%APPDATA%\OnEum`(라이브러리와 설정)과 `%LOCALAPPDATA%\OnEum`(이미지 캐시와 로그)입니다.
- 네트워크 폴더(WebDAV)의 비밀번호는 Windows의 **자격 증명 관리자**에 저장됩니다("OnEum network folder: …"로 보이고, 거기서 지울 수도 있습니다). 이 안내에서 키체인에 관한 설명은 Windows에서는 자격 증명 관리자를 뜻합니다.
- 시작할 때 오류 창이 뜨면 그 창에서 Ctrl+C로 내용을 복사할 수 있습니다. 그래픽 장치를 준비하지 못했다고 나오면 그래픽 드라이버를 업데이트하거나, 가상 머신에서는 3D 가속을 켠 뒤 다시 실행하세요. 자세한 기록은 `%LOCALAPPDATA%\OnEum\Logs\oneum.log`에 있습니다.
- Windows판은 macOS판과 같은 코드로 만들지만, 이 버전은 실제 Windows에서의 확인을 아직 거치지 않았습니다.
