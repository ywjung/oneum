## Windows에서 다른 점
- 메뉴 막대는 창 맨 위에 있습니다. 단축키는 Ctrl 키로 누릅니다.
- 창을 닫으면 프로그램이 끝나고 재생도 멈춥니다. 이 안내에서 Dock에 관한 설명은 Windows에는 해당하지 않습니다.
- 음악 파일을 `OnEum.exe`에 끌어다 놓거나 "연결 프로그램"으로 열면 그 파일을 재생합니다.
- 키보드의 미디어 키와 Windows의 미디어 표시에는 연결되어 있지 않습니다.
- 출력 품질의 **곡의 샘플레이트로 출력**과 **독점 출력**은 macOS에서만 동작합니다. Windows에서는 시스템이 정한 샘플레이트로 맞춰 재생합니다. **메모리 재생**과 VU 미터는 똑같이 쓸 수 있습니다.
- 데이터 위치는 `%APPDATA%\OnEum`(라이브러리와 설정)과 `%LOCALAPPDATA%\OnEum`(이미지 캐시와 로그)입니다.
- Windows판은 macOS판과 같은 코드로 만들지만, 이 버전은 실제 Windows에서의 확인을 아직 거치지 않았습니다.
